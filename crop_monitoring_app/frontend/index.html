About This System

Master's Thesis Project - Intelligent Agricultural Monitoring

This application demonstrates an intelligent system for monitoring the condition of agricultural crops using state-of-the-art computer vision and neural network technologies. The system can analyze plant images from both controlled datasets (PlantVillage) and real field conditions, providing accurate disease detection with explainable AI visualizations.

Model Architectures

Four different neural network architectures for comprehensive comparison

Baseline CNN

Custom 4-layer convolutional neural network designed for plant disease classification

  • Parameters 1.2M
  • Size 4.8 MB
  • Speed Fast

EfficientNet-B0

State-of-the-art efficient architecture with compound scaling, pre-trained on ImageNet

  • Parameters 4.0M
  • Size 16.2 MB
  • Speed Medium

MobileNet-V2

Lightweight architecture optimized for mobile and edge devices

  • Parameters 2.3M
  • Size 9.1 MB
  • Speed Very Fast

Hybrid CNN-Transformer

Advanced architecture combining CNN feature extraction with transformer self-attention

  • Parameters 25.6M
  • Size 102.4 MB
  • Speed Slower
